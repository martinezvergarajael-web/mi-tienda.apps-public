Gestión de sensores

Qué son los sensores, cuáles incluyen los móviles y cómo habilitarlos, leerlos y procesar su información.

3.1 Definición de sensores

Un sensor es un componente de hardware (o virtual, calculado por software) que mide una magnitud física del entorno o del propio dispositivo —aceleración, giro, luz, presión, campo magnético, posición— y la convierte en una señal digital que las aplicaciones pueden leer. Los sensores permiten que la app “perciba” el mundo: rotar la pantalla, contar pasos, navegar con mapas o ajustar el brillo.

3.3 Proceso de gestión de sensores

1

Habilitación

Verificar que el sensor existe en el dispositivo, declarar permisos (ACCESS_FINE_LOCATION, ACTIVITY_RECOGNITION, CAMERA…), solicitarlos en tiempo de ejecución y obtener el SensorManager.

2

Obtención

Registrar un listener con una frecuencia de muestreo (SENSOR_DELAY_NORMAL, GAME, FASTEST) y recibir los eventos en onSensorChanged.

3

Procesamiento

Filtrar el ruido (filtro paso bajo/alto), convertir unidades, interpretar los valores (detectar sacudida, orientación) y mostrar o almacenar el resultado.

4

Liberación

Dar de baja el listener en onPause() para ahorrar batería.

Ejemplo: leer el acelerómetro en Android (Kotlin)

class MainActivity : AppCompatActivity(), SensorEventListener {
    private lateinit var sensorManager: SensorManager
    private var acelerometro: Sensor? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        // 1. HABILITACIÓN: obtener el servicio y comprobar que existe el sensor
        sensorManager = getSystemService(SENSOR_SERVICE) as SensorManager
        acelerometro = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)
        if (acelerometro == null) Toast.makeText(this, "Sin acelerómetro", Toast.LENGTH_SHORT).show()
    }

    // 2. OBTENCIÓN: registrar listener
    override fun onResume() {
        super.onResume()
        acelerometro?.also { sensorManager.registerListener(this, it, SensorManager.SENSOR_DELAY_NORMAL) }
    }

    // 4. LIBERACIÓN
    override fun onPause() {
        super.onPause()
        sensorManager.unregisterListener(this)
    }

    // 3. PROCESAMIENTO
    override fun onSensorChanged(e: SensorEvent) {
        val x = e.values[0]; val y = e.values[1]; val z = e.values[2]
        val magnitud = Math.sqrt((x*x + y*y + z*z).toDouble())
        if (magnitud > 15) Log.d("SENSOR", "¡Sacudida detectada!")
    }

    override fun onAccuracyChanged(s: Sensor?, accuracy: Int) {}
}

val cliente = LocationServices.getFusedLocationProviderClient(this)

    loc?.let { Log.d("GPS", "Lat=${it.latitude} Lon=${it.longitude}") }

Buenas prácticas: pide solo los permisos necesarios, explica al usuario para qué los usas, usa la frecuencia de muestreo más baja posible y siempre cancela el registro del sensor al salir de la pantalla.
