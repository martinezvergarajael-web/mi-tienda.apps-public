Librerías y toolkits para desarrollo móvil

Diferencia entre librería y toolkit, librerías especializadas y toolkits para crear apps móviles.

6.1 ¿Qué es una librería y qué es un toolkit?

Librería (library)

Conjunto de funciones, clases y utilidades reutilizables que resuelven una tarea concreta (peticiones HTTP, cargar imágenes, parsear JSON). Tu código la llama cuando la necesita y tú controlas el flujo de la aplicación.

Ejemplos: Retrofit, Gson, Glide, Room.

Toolkit

Conjunto más amplio e integrado de herramientas, componentes de interfaz, APIs y utilidades para construir aplicaciones completas en una plataforma. Suele incluir widgets, compilador, emulador y herramientas de depuración.

Ejemplos: Android SDK + Jetpack, Jetpack Compose, SwiftUI/UIKit, Flutter, React Native, .NET MAUI.

Diferencia clave: una librería es una pieza que usas; un toolkit es una caja de herramientas completa. Un framework además define la estructura y es quien llama a tu código (inversión de control).

Ejemplo: agregar una librería con Gradle

// app/build.gradle.kts
dependencies {
    implementation("com.squareup.retrofit2:retrofit:2.11.0")
    implementation("com.squareup.retrofit2:converter-gson:2.11.0")
    implementation("com.github.bumptech.glide:glide:4.16.0")
    implementation("androidx.room:room-runtime:2.6.1")
}

Después de editar el archivo, se pulsa Sync Now en Android Studio. (Verifica siempre la última versión en la documentación oficial de cada librería.)

Ionic / CapacitorHTML, CSS, JSHíbrido (WebView)Fácil para desarrolladores webMenor rendimiento que nativo

¿Cuál elegir?

  • Máximo rendimiento / hardware → nativo (Android o iOS).
  • Una sola base de código → Flutter o React Native.
  • Equipo con experiencia web → React Native o Ionic.
  • Compartir lógica manteniendo UI nativa → Kotlin Multiplatform.

import 'package:flutter/material.dart';

      appBar: AppBar(title: const Text('Hola móvil')),

  );
}
