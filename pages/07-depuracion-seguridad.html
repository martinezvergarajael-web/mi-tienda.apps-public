Depuración y seguridad

Cómo encontrar y corregir errores, qué herramientas ofrece el IDE y cómo proteger la app y sus datos.

7.1 ¿Qué es la depuración y la seguridad?

Depuración (debugging)

Proceso de encontrar, analizar y corregir errores (bugs) en el código. Se observa el programa mientras se ejecuta: valores de variables, flujo de ejecución, uso de memoria y red, hasta identificar la causa del fallo.

Seguridad

Conjunto de prácticas que protegen la app, los datos del usuario y la comunicación contra accesos no autorizados, filtración o manipulación. Se apoya en los principios de confidencialidad, integridad y disponibilidad.

Log.v("MiApp", "Mensaje detallado")

Log.i("MiApp", "Información")
Log.w("MiApp", "Advertencia")
Log.e("MiApp", "Error al guardar", excepcion)

Pasos para depurar con breakpoints

  1. Haz clic en el margen izquierdo de una línea para poner un breakpoint.
  2. Pulsa Debug (ícono del insecto) en lugar de Run.
  3. Cuando la ejecución se detenga, revisa las variables en el panel Variables.
  4. Avanza con Step Over (F8) o entra a una función con Step Into (F7).
  5. Corrige el código y vuelve a ejecutar.

7.3 Seguridad en aplicaciones móviles

Datos locales

  • Cifrar información sensible (Jetpack Security, SQLCipher).
  • Guardar tokens en Android Keystore / iOS Keychain.
  • No guardar contraseñas en texto plano.

Comunicación

  • Usar siempre HTTPS/TLS.
  • Certificate pinning.
  • Validar respuestas del servidor.

Autenticación

  • OAuth 2.0 / JWT con expiración.
  • Biometría (BiometricPrompt).
  • Autenticación multifactor.

Código

  • Ofuscar y reducir con R8/ProGuard.
  • No incluir claves de API en el código ni en Git.
  • Validar entradas del usuario (evitar inyección SQL).

Permisos

  • Principio de mínimo privilegio.
  • Pedir permisos solo cuando se necesiten.
  • Marcar componentes con exported="false".

Distribución

  • Firmar la app con llave protegida.
  • Actualizar dependencias con vulnerabilidades.
  • Seguir OWASP MASVS.

Ejemplo: consulta segura contra inyección SQL

// [X] Inseguro
db.rawQuery("SELECT * FROM usuario WHERE nombre = '" + entrada + "'", null)

// [OK] Seguro: parámetros enlazados
db.rawQuery("SELECT * FROM usuario WHERE nombre = ?", arrayOf(entrada))

Ejemplo: guardar datos cifrados

val masterKey = MasterKey.Builder(context)
    .setKeyScheme(MasterKey.KeyScheme.AES256_GCM).build()

val prefs = EncryptedSharedPreferences.create(
    context, "secretos", masterKey,
    EncryptedSharedPreferences.PrefKeyEncryptionScheme.AES256_SIV,
    EncryptedSharedPreferences.PrefValueEncryptionScheme.AES256_GCM)

prefs.edit().putString("token", "abc123").apply()
